# Security policy

## Supported version

Security fixes are applied to the latest supported release candidate or stable release. Use the latest published release when reporting an issue.

## Reporting a vulnerability

Do not report suspected vulnerabilities in public issues or pull requests. Use GitHub's private vulnerability reporting for this repository when enabled, or contact the repository owner privately through GitHub. Include affected version, impact, reproduction steps, and relevant logs after removing credentials, private keys, addresses, and other sensitive node data.

PNM backups contain secrets. Never attach an unredacted backup or Core configuration to a report.
